# Payments Simulation

A single-page, simulated Seamless FM dashboard for technician payouts and job margins.

- **Live**: one work order's payment moving from job completion to technician paid, plus today's running totals.
- **Business**: billings, technician cost, gross profit and margin against the 25–40% target, by trade, region and client, with the client cash cycle and receivables aging.
- **Payments**: speed from sign-off to paid, human review outcomes, payments per work order, timing heatmap, top technicians.
- **Work orders**: searchable ledger with per-payment timelines and job economics.

Model: about 4,000 work orders and 8,000+ technician payments a month, $500–$700 average job. All data is generated in the browser and is not real.

Static site: open `index.html` or deploy the folder as-is (no build step).
